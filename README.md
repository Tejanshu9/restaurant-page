# 🍽️ The Royal Prince Platter  
### A Dynamic Restaurant Website Built with JavaScript (The Odin Project)

The **Royal Prince Platter** is a fully dynamic restaurant website created as part of **The Odin Project’s JavaScript curriculum**.  
All page content (Home, Menu, Contact) is generated entirely using JavaScript — no static HTML inside the main template.

This project highlights DOM manipulation, modular JavaScript, and Webpack bundling.

---

## 🚀 Features

### ✔️ Dynamic Tab Navigation  
- Home  
- Menu  
- Contact  
Each section loads dynamically without page refresh.

### ✔️ Clean, Modern UI  
- Minimalistic design  
- Hover animations  
- Card-style menu items  
- Responsive layout

### ✔️ Organized Code Structure  
- Modules for Home, Menu, Contact  
- Helper function for generating menu items  
- Webpack for bundling and live development server

### ✔️ Accessible & Semantic  
- Proper roles & aria labels  
- Clear typography  
- User-friendly layout
